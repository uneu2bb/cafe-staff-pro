# Cafe Staff Pro

نظام ويب احترافي لإدارة حضور وانصراف الموظفين في الكافيهات والمطاعم.

## المميزات

- تسجيل حضور/انصراف (رقم سري، QR، دعم أجهزة البصمة)
- لوحة تحكم إدارية كاملة
- إدارة الموظفين والورديات
- حساب ساعات العمل والتأخير تلقائياً
- نظام الإجازات والرواتب
- تقارير قابلة للتصدير (Excel / PDF)
- صلاحيات متعددة (مالك، مدير، محاسب، مشرف، موظف)
- دعم الفروع المتعددة
- واجهة عربية كاملة RTL
- قاعدة بيانات سحابية (Supabase + PostgreSQL)

## التقنيات

- Frontend: Next.js 15 + TypeScript + Tailwind CSS
- Backend/DB: Supabase (PostgreSQL + Auth + RLS + Realtime)
